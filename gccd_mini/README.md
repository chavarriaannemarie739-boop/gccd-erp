# 高齿小程序

## 你只需要会这两件事

1. 用 **微信开发者工具** 打开这个文件夹（和现在一样）。
2. 点 **预览** 或 **上传**，发布新版本。

底部为 **三个** Tab：**工作台**、**设备**、**我的**。工单 / 物料 / 能耗只从工作台进，这三页底部有与主 Tab 一致的导航，可切回工作台或设备、我的（避免与「工作台」里三个入口在底栏重复）。

改完代码保存后，开发者工具里重新编译一下，就能预览；不用管下面那些字也行。

---

## 给以后换电脑、或同事第一次用这个项目的说明（可选）

第一次在这台电脑上打开项目时，如果提示找不到 Vant 组件：

1. 在这个项目文件夹里打开「终端 / 命令行」，输入：`npm install` 然后回车（等它跑完）。
2. 回到微信开发者工具，点菜单 **工具 → 构建 npm**。
3. 再点编译、预览。

平时你一直用同一台电脑、项目能正常打开的话，**不用做上面这两步**。

# 车间电视 APK 试机清单

## 试机前准备

- [x] 服务器已配置 `[KIOSK] DASHBOARD_KEY` 与 `public/dv/dv-config.json`（Web `/dv/` 已验收）
- [ ] 电视/盒子可访问 `https://gccd.xnssoft.com`
- [ ] 已安装 `gccd_tv`  release APK

## 功能验收

- [ ] 启动无登录界面，直接进入「生产总览」全屏
- [ ] 无浏览器地址栏、无系统导航栏（沉浸式）
- [ ] 横屏显示，1920×1080 缩放正常
- [ ] KPI、计划轮播、饼图、能耗、设备与 Web 版一致
- [ ] 断网后出现「重新连接」，恢复网络后自动/手动重试成功
- [ ] 屏幕常亮，不会自动休眠（需 TV 系统允许）

## 稳定性（建议 24h）

- [ ] 连续运行 24 小时无崩溃
- [ ] 内存无明显持续上涨
- [ ] 定时刷新（约 60s）数据正常更新

## 批量安装

- U 盘拷贝 APK → 电视文件管理器安装，或
- ADB：`adb install -r app-release.apk`

## 问题反馈请提供

- 电视品牌型号、Android 版本、分辨率
- 现场网络方式（WiFi/有线）
- 截图或录屏

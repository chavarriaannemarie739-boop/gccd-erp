## 引言
本文件面向高齿传动项目的移动端与后台管理系统，系统性梳理核心业务模块的功能与实现，覆盖生产管理（工单管理、工序管理、生产报表）、设备管理（设备台账、维护记录、维修管理）、物料管理（采购管理、入库出库、库存盘点）、能源管理（电耗统计、能耗分析）、质量管理（质检项目、质检记录、质量统计）、人员管理（工资管理、考勤记录、绩效统计）。文档提供业务流程图、数据流转与用户操作指南，帮助研发与运营人员快速理解与使用。

## 项目结构
项目采用前后端分离架构：
- 移动端（小程序）：gccd_mini，负责业务前端交互与数据展示。
- 后端（ThinkPHP）：gccd_server，提供REST风格API与业务服务。
- 后台管理前端（Vue）：yarn，提供MES大屏与各类业务管理界面。

## 核心组件
- 生产管理
  - 工单管理：列表、筛选、分页、完成标记、报工跳转、扫码报修。
  - 工序管理：根据工艺编码获取工序清单，逐工序报工与能耗录入。
  - 生产报表：能耗列表与统计接口。
- 设备管理
  - 设备台账：设备二维码扫码触发报修。
  - 维护记录：维修记录详情与列表，计算维修时长。
  - 维修管理：维修记录查询与图片预览。
- 物料管理
  - 采购/入库：入库列表与查询。
  - 出库/领料：领料记录列表与状态展示。
  - 库存盘点：生产盘点记录与查询。
- 能源管理
  - 电耗统计：按日期范围统计能耗。
  - 能耗分析：后台大屏轮询刷新。
- 质量管理
  - 质检项目：按工序名称与日期范围查询。
  - 质检记录：列表、详情、新增与删除。
  - 质量统计：后台统计视图。
- 人员管理
  - 工资管理：员工工资列表与日工资查询。
  - 考勤记录：移动端工资记录展示。
  - 绩效统计：后台统计视图。

## 详细组件分析

### 生产管理模块

#### 工单管理
- 功能要点
  - 列表分页与筛选（按规格/型号/客户型号），支持下拉刷新与上拉加载。
  - 完成标记：基于报工数量与任务数量判断，弹窗确认后调用编辑接口。
  - 报工跳转：根据工单的工艺编码跳转到工序页面，逐工序报工与能耗录入。
  - 扫码报修：支持二维码/条形码扫码，填写原因与图片上传后提交报修。
- 关键流程

```mermaid
sequenceDiagram
participant U as "用户"
participant WO as "工单页面(workOrder.js)"
participant API as "后端API"
participant PROC as "工序页面(workOrderProcess.js)"
U->>WO : 查看进行中/已完成工单
WO->>API : 获取工单列表
API-->>WO : 返回列表与报工汇总
U->>WO : 点击“报工”
WO->>PROC : 跳转并传入routing_code与id
PROC->>API : 按routing_code获取工序
API-->>PROC : 返回工序清单
PROC-->>U : 逐工序提交报工/能耗
```

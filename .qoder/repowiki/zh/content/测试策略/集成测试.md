## 引言
本文件面向“高齿传动”项目的集成测试，覆盖以下方面：

- 测试自动化与持续集成配置思路

## 故障排查指南
- 统一响应结构
  - 成功：code=200，msg 为操作成功提示，data 为业务数据
  - 失败：code 非 200，message 为错误描述
- 错误码对照
  - 200：操作成功
  - 400：参数错误
  - 401：登录已失效
  - 402：第三方账号未注册
  - 403：无权限
  - 404：接口地址错误
  - 429：操作过于频繁
  - 500：服务器错误
- HTTP 错误解析
  - 百度云 HTTP 客户端在非 2xx 时尝试解析 JSON 错误体，提取 message/code
  - 华为云 OBS 在解析 JSON 错误时设置 requestId、exceptionCode、exceptionMessage
